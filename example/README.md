# kinetic_player Example

演示 [kinetic_player](../) 播放器的 Example 应用。

## 快速运行

```bash
# 从 example 目录
flutter pub get
flutter run -d macos    # 或真机 iOS / Android
flutter run -d windows
flutter run -d linux
```

SGPlayer 见 [../doc/DARWIN_SGPLAYER.md](../doc/DARWIN_SGPLAYER.md)。  
桌面 libmpv 见 [../doc/DESKTOP_MPV.md](../doc/DESKTOP_MPV.md)。  
更多说明见 [../doc/EXAMPLE.md](../doc/EXAMPLE.md)。
